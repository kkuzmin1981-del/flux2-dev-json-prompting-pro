# flux2-dev-json-prompting-pro

🌐 [English](readme.md) · [Русский](readme-rus.md) · [中文](readme-chn.md)

**FLUX.2 [dev] — Профессиональная система JSON-промптов** — универсальный агентский скилл для любого ИИ-агента.

Скилл превращает простые запросы пользователя («чашка кофе на столе», «неоновая улица ночью») в технически точные, профессионально выстроенные JSON-промпты для текстово-изображательной модели **FLUX.2 [dev]** (Black Forest Labs) — с реальными терминами из камерной, оптической, световой и цветовой науки вместо размытых прилагательных. Вы удивитесь, как сильно отличаются сплошные промпты от профессионального JSON. Погрузитесь в профессиональный FLUX 2.

## Что делает скилл

- **Полная JSON-схема** — JSON это структурированный формат промпта, который FLUX 2 официально понимает для профессиональных целей; модель читает JSON точнее, чем сплошной текст. Все поля обязательны, порядок полей фиксирован, `aspect_ratio` — последнее как рекомендация пользователю по выбору соотношения.
- **Справочная терминология** — камеры, объективы, ракурсы, планы, фокус, диафрагмы, ISO, плёночные эмуляции, таксономия стилей, композиционные приёмы, градиентные формулировки и соотношения сторон выбираются из встроенных справочников, а не изобретаются на лету.
- **Физика цвета и света** — иерархия палитры 60-30-10 с HEX-якорением, цветовая температура в Кельвинах, отношения key:fill и световой каркас SQTSI (Source → Quality → Temperature → Shadow → Interaction).
- **Рекомендация → подтверждение** — по каждому отсутствующему параметру модель предлагает профессиональное значение с короткой причиной; промпт финализируется только после согласия пользователя (или его точечных правок).

## Формат JSON-промпта

```json
{
  "scene": "",
  "subjects": [
    {
      "type": "",
      "description": "",
      "pose": "",
      "position": "",
      "action": "",
      "colors": []
    }
  ],
  "style": "",
  "color_palette": [],
  "lighting": "",
  "mood": "",
  "background": "",
  "composition": "",
  "camera": {
    "model": "",
    "angle": "",
    "lens": "",
    "f-number": "",
    "ISO": "",
    "distance": "",
    "focus": "",
    "depth_of_field": ""
  },
  "aspect_ratio": ""
}
```

## How to use

При вызове скилла пишите обычный запрос с описанием того, что хотите. Можете написать краткие тезисы:

> «Придумай промпт и детали к нему. Стиль 80-х, как в сериале: белый коп и чёрный детектив — напарники, Майами, стоят у автомобиля, ночь, городские огни сильно размыты, разнообразные цвета...»

Далее модель проведёт обдумывание и предложит варианты по всем параметрам, которые вы не указали в запросе, — каждый с короткой причиной, основанной на сцене, — и попросит подтвердить или скорректировать. Если вас всё устроит, напишите «Да» (или укажите конкретные изменения). После этого просто дождитесь окончания — будет выведен готовый JSON-промпт.

## Рекомендации

Рекомендуется использовать LLM с хорошим следованием инструкциям, которая «не срезает углы». К примеру: Qwen 3.8, GLM, ...
